# Drones
Şu ana kadar uğraştığım drone projelerine dair belgeler bulunur

# Mağara Operasyonları İçin Yarasa

TSK'nın en fazla şehit verdiği operasyonların başında kapalı alan operasyonları geliyor. Bu operasyonlarda kullanılabilmesi için Teknofest yarışması için drone tasarımı yaptık. Dronumuzun asıl öne çıkan özelliği GPS'siz alanlarda da çalışabilmesi olmuştur.
